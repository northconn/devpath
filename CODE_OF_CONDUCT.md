# Código de conduta

Buscamos um espaço profissional, respeitoso e acolhedor. Trate dúvidas de iniciantes com clareza; critique ideias e mudanças, nunca pessoas. Não publique dados pessoais, clínicos, credenciais ou conteúdo discriminatório. Relate conduta inadequada ao mantenedor do repositório de forma privada, incluindo somente o contexto necessário.
