# Trilha de aprendizagem

Siga as lições na ordem. Cada uma tem um resultado observável, exercício, desafio e checkpoint; abra o spoiler somente depois de registrar uma tentativa.

| Unidade | Vitória observável | Evidência |
| --- | --- | --- |
| 0 | programa inicial executa | saída segura em `PROGRESS.md` |
| 1 | entende execução local | observação de processo e `PATH` |
| 2 | domina arquivos e shell | árvore de laboratório criada |
| 3 | interpreta uma falha de rede | tabela de diagnóstico preenchida |
| 4 | executa serviços isolados | `docker compose ps` saudável |
| 5 | persiste e consulta dados sintéticos | `add`, `get` e health check |
| 6 | depura uma falha preparada | nota com comando, stack trace e correção |
| 7 | colabora com Git e GitHub | branch, conflito resolvido e PR revisável |
| 8 | organiza regra Python em módulos | teste e verificações executados por `uv` |
| 9 | compara TypeScript com Python | scripts ESM e validação em runtime explicados |
| 10 | protege mudança com qualidade e CI | ciclo vermelho–verde e diagnóstico registrado |
| 11 | entrega melhoria reproduzível | rubrica, PR, CI quando disponível e retrospectiva |

O [starter](../projects/vet-environment-lab/starter/README.md) é seu local de prática; a [solução](../projects/vet-environment-lab/solution/README.md) é referência, não ponto de partida. Siga para o [índice das Unidades 0–11](../modules/01-development-environment/README.md).
