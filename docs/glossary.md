# Glossário essencial

| Português | Inglês | Definição curta |
| --- | --- | --- |
| diretório | directory | pasta que agrupa arquivos |
| terminal | terminal | aplicação que recebe texto e mostra resultado |
| shell | shell | programa que interpreta comandos no terminal |
| processo | process | programa em execução, com recursos próprios |
| porta | port | número que identifica um serviço de rede no computador |
| variável de ambiente | environment variable | valor de configuração passado ao processo |
| caminho | path | endereço de arquivo ou diretório |
| runtime | runtime | software que executa uma linguagem, como Python ou Node.js |
| imagem | image | receita imutável para criar containers |
| container | container | processo isolado criado a partir de uma imagem |
| volume | volume | armazenamento persistente gerenciado pelo Docker |
| cache | cache | cópia temporária para acesso mais rápido |
| TTL | time to live | tempo de vida de um valor temporário |
| fonte de verdade | source of truth | local autoritativo do dado |
| DNS | Domain Name System | serviço que associa nome a endereço IP |
