# Módulo 1 — Ambiente de desenvolvimento

Este módulo transforma uma instalação em um ambiente que você consegue explicar e diagnosticar. Trabalhe nas lições em ordem; cada exercício expande o **Vet Environment Lab** com dados fictícios.

| Lição | Resultado | Tempo |
| --- | --- | --- |
| [00](lessons/00-orientation.md) | primeiro programa e registro seguro | 45–75 min |
| [01](lessons/01-how-computers-work.md) | modelo mental da execução | 75–110 min |
| [02](lessons/02-operating-systems.md) | arquivos e ambientes | 90–130 min |
| [03](lessons/03-networking-and-security.md) | diagnóstico básico de rede | 100–140 min |
| [04](lessons/04-servers-and-containers.md) | serviços locais isolados | 110–155 min |
| [05](lessons/05-databases.md) | persistência e cache | 120–170 min |
| [06](lessons/06-vscode.md) | depurar uma falha com evidências | 90–130 min |
| [07](lessons/07-git-and-github.md) | branch, conflito e PR revisável | 130–180 min |
| [08](lessons/08-modern-python.md) | módulos, `uv` e testes Python | 150–210 min |
| [09](lessons/09-modern-typescript.md) | ESM, tipos e validação em runtime | 100–145 min |
| [10](lessons/10-testing-and-quality.md) | vermelho–verde e investigação de CI | 150–210 min |
| [11](lessons/11-final-challenge.md) | entrega reproduzível e retrospectiva | 240–360 min |
