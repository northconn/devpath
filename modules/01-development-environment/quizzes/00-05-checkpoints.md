# Checkpoints das Unidades 0–5

## Perguntas

1. **Múltipla escolha.** Um comando não é encontrado. Qual é a primeira evidência mais direta? (A) apagar cache; (B) `command -v NOME`; (C) usar `sudo`; (D) encerrar processos.
2. **Interpretação de saída.** `docker compose --env-file .env port postgres 5432` imprimiu `127.0.0.1:5432`. O que isso prova? O que ainda não prova?
3. **Múltipla escolha.** Qual elemento persiste dados quando um container é recriado? (A) imagem; (B) volume; (C) log; (D) tag.
4. **Resposta aberta.** `curl` recebeu HTTP 404. Que etapas de uma requisição provavelmente já ocorreram e qual hipótese esse código sugere?
5. **Resposta aberta.** PostgreSQL está saudável e Redis indisponível. Como a aplicação deve responder e qual evidência você registraria?

Compare sua resposta com o [gabarito comentado](00-05-checkpoints-answers.md) somente depois de tentar.
