# Como contribuir

Use português brasileiro para conteúdo de aprendizagem e inglês para nomes de arquivos, comandos e identificadores. Abra uma issue antes de uma mudança grande. Para uma alteração pequena: crie uma branch descritiva, confira `git diff`, faça um commit curto no imperativo e explique a evidência de validação no pull request.

Nunca envie segredos, `.env`, dados pessoais, dados clínicos ou material sem direito de redistribuição. Prefira fontes oficiais e informe URL, seção e data de verificação ao adicionar uma referência.
